# Démonstration publique
Les six documents, les compteurs et les quatre événements sont entièrement fictifs. Les fichiers source sont dans apps/frontend/src/demo.ts. Aucun document gouvernemental réel, token, répertoire d’identité ou clé n’est inclus. La démonstration ne téléverse pas de fichiers et n’appelle pas le backend. Le badge prototype reste visible.

Scénarios : filtrer les documents, consulter un texte synthétique, naviguer vers classification/audit, ouvrir le formulaire de dépôt et vérifier son message de démonstration. Basculer le thème et tester la navigation mobile.
